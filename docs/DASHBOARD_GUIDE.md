# Dashboard Guide

Use the live Streamlit deployment for the fastest walkthrough:

- https://intent-aware-cloud-governance.streamlit.app/

## Recommended 60-Second Flow

1. Open the **Overview** page for the system summary.
2. Move to the **Prevention Engine** view to show pre-provision decisions.
3. Highlight an `AUTO_CORRECT` example.
4. Open **Runtime & Savings** to show prevented-cost impact.
5. Finish on **Learning System** to show convergence and feedback.
